# Mithila Makhana Co. - Direct Madhubani Farm Supply

Direct farm-fresh GI-tagged Madhubani Makhana website and bulk supply platform managed by **Girish Jha**.

## 🌾 Features
- **GI-Tagged Madhubani Makhana Catalog**: 5kg farm bags, 10kg commercial lots, roasted peri-peri & Himalayan pink salt.
- **Direct UPI & ICICI QR Scanner**: Quick checkout with verified UPI (`girishkumarjha28@okicici`) and scanner.
- **Dispatch Tracking & Pincode Checker**: Built-in logistics verification.
- **Responsive Modern UI**: Built with React 19, Vite, and Tailwind CSS.

## 🚀 Quick Start (Apne Computer Par Kaise Chalayein)

1. **Repository Clone Karein:**
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd <your-repo-name>
   ```

2. **Dependencies Install Karein:**
   ```bash
   npm install
   ```

3. **Development Server Start Karein:**
   ```bash
   npm run dev
   ```
   Ab browser me `http://localhost:3000` open karein.

4. **Production Build Banayein:**
   ```bash
   npm run build
   ```
